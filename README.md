# RaySlash

RaySlash is a GNOME Shell extension that draws a temporary,
accent-colored slash when the pointer is dragged over the empty desktop.

The intended effect is a stretched, tapered blade shape with:

- a bright foreground using the current GNOME accent color;
- a dark semitransparent afterimage;
- a short foreground fade;
- a slightly longer tail fade;
- no input interception outside the empty desktop.

## Development target

- Fedora 44
- GNOME Shell 50
- Wayland
- GJS ES modules
